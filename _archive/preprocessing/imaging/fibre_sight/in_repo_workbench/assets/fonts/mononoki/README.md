# mononoki

Fibre Sight uses these local copies so the GUI and saved diagnostics use the same typeface on lab machines. The files are mononoki 1.006 by Matthias Tellen, taken from [release 1.6](https://github.com/madmalik/mononoki/releases/download/1.6/mononoki.zip), and are distributed under the [SIL Open Font License 1.1](https://github.com/madmalik/mononoki/blob/main/LICENSE). `mononoki.zip` contains the same eight OTF and TTF files stored alongside it.
